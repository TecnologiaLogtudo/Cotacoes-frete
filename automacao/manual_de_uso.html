Manual de Uso - Cotação Logtudo

Este manual descreve o fluxo da página web de processamento de cotações.

1. Acesso

  • Acesse a tela principal de cotação no domínio configurado.
  • As credenciais informadas na interface ficam salvas somente no navegador (localStorage).

2. Preenchimento do formulário

  • Informe Login e Senha do site Logtudo.
  • Informe Data de Cotação e Validade.
  • Selecione a planilha no botão de upload (arquivo .xlsx).

3. Execução

  • Clique em Iniciar processamento.
  • O sistema cria um job assíncrono via RQ/Redis.
  • O processamento considera as primeiras 100 linhas de dados e ignora/remover linhas sem Número.

4. Acompanhamento de logs

  • Os logs são atualizados automaticamente (polling).
  • Você pode pausar/retomar o auto-scroll para leitura.
  • Ao final, o status indica SUCCESS ou FAILURE.

5. Solução de problemas

  • Se o upload falhar, confirme se o arquivo é .xlsx.
  • Se houver erro de autenticação, revise login/senha.
  • Se o job ficar travado, valide saúde de redis e rq-worker.
Dica: mantenha a planilha com cabeçalho na linha 3 e dados consistentes nas colunas esperadas para evitar rejeições.
